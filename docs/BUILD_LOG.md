## 画质实验（`?look=pro`，默认画面不变）

起因：分析图风格"太低级、没质感"。差距不在引擎（同样是 Three.js），在渲染管线和素材：
`<Canvas flat>` 等于没开色调映射，画面发灰发平；只有环境光 + 一盏平行光；材质是纯色；家具是圆角盒子；没有后期；只有正交等轴测。

### 第 0 轮：同一套户型，只换渲染

- A → B（透视、低角度暖阳 + 软阴影、柔光箱天光、AO / 泛光 / 移轴 / 暗角 / SMAA、Neutral 色调映射）提升最大，像桌上的实体模型，约 43 fps。
- B → C（Poly Haven 的 CC0 贴图 + 茶几、绿植模型）：鸟瞰距离下只是细节。
- 人眼高度实时渲染：没有反弹光，墙和天花板发灰，像游戏画面。
- 浏览器路径追踪（three-gpu-pathtracer）：最接近效果图，但每个采样约 3.7 秒，整条片要 47 小时，只能出静帧。
- 结论：鸟瞰用 B/C 的管线；人眼高度靠 Blender 烘焙光照 + 一套近看经得住的家具。

### 第 1 轮：导演接管透视相机，氛围预设

- `?mood=m1|m2|m3|m4`：午后暖阳 / 奶油阴天 / 蓝调开灯 / 书桌上的微缩模型；`?tod=0..1` 从正午到夜里插值太阳、天光、曝光、室内灯。
- 相机距离按画面比例自动贴合，横版、竖版都装得下。1050 Ti 上 45–50 fps。

### 第 2 轮：规则软装、看得清的白天

- `src/look/decor.js`：只看户型数据（房间类型、家具、墙、门窗）摆地毯、抱枕、灯、绿植、挂画、窗帘、床品、厨卫小物，避开门的开启区和家具。opus55 摆 64 件。
- `mood=m2a|m2b|m2c`：光更硬、AO 更重、墙顶剖切面压深（胡桃木 + 炭灰 / 鼠尾草绿 / 陶土橙）；选定 m2a。m3 重做成同一个家的蓝调时刻。
- `seq=final` 时间线：书桌开场 → 墙 → 门窗 → 家具和软装 → 一天过去 → 蓝调开灯。

### 第 3 轮：人眼高度 + 烘焙光照

实时渲染从人眼高度看屋里很平：没有反弹光。路径追踪又太慢。所以把光照放到 Blender 里烘焙：间接光、墙角和天花板上的暖光、家具底下的接触阴影就都有了，页面照样实时渲染。

```bash
node tools/fetch-assets.mjs
blender -b --factory-startup -P tools/blender/furniture.py
node tools/bake-export.mjs
blender -b --factory-startup -P tools/blender/bake.py -- --set opus55-m3 --res 2048 --samples 384 --ref
```

- 静态物体（墙、地、天花板、家具、地毯、窗帘）用光照贴图：漫反射 = 反照率 × 烘焙的光（直射 + 反弹），高光照旧实时算，木头、地板的反光还在。
- 动态的小东西（灯具、绿植、摆件、抱枕）只当遮挡物参与烘焙，自己靠环境探针和实时灯照亮。
- 光照贴图在墙里、地板下的无效像素先找出来（看出去一大半是物体背面的像素），用旁边的有效像素补上，墙角不出黑边；最后 OIDN 降噪。
- 2048²、384 采样：光照贴图约 6 分钟，加探针和参考图整套 15 分钟（当时显卡还被别的任务占着，92–95°C）。OptiX 在这张卡上烘出来是空的，要用 CUDA。
- Blender 脚本建的家具：沙发、茶几、电视柜和电视、餐桌椅（`public/assets/hero/furniture.glb`）。人眼视角 22.8 fps。

### 第 4 轮：每个房间都扛得住人眼近看

```bash
blender -b --factory-startup -P tools/blender/furniture.py      # 加上 furniture_rooms.py：床、床品、衣柜、书桌、整体厨房、冰箱、卫生间
node tools/bake-export.mjs
blender -b --factory-startup -P tools/blender/bake.py -- --set opus55-m3 --res 4096 --samples 512
blender -b --factory-startup -P tools/blender/night_plate.py    # 阳台夜景 n2 / n3 的外滩背景板
node tools/room-shots.mjs --dir out/look/round4                 # 每个房间一张人眼静帧
```

- 整套房子一张 4096² 光照贴图，按物体种类给像素密度（家具、床品、窗帘高，天花板、楼板低）；看不见的面（天花板顶面、楼板上下面、墙顶）展 UV 前删掉。
- 窗户和阳台开口挂天光入口（portal），灯罩、灯带改成自发光，墙上的光斑不再一片噪点。
- 灯色往中性收（之前 2400K 左右，白墙发黄发灰），相当于白平衡定在 3000K：屋里暖白、窗外深蓝。
- 反射：每个房间一张探针，相机在哪间就用哪间；玻璃、镜子按房间的盒子做视差校正；离探针 2.3 米以内的灯具不进探针（之前吊灯在阳台玻璃里的倒影大得离谱）。
- OIDN 之后再修一遍：亮点压回 3×3 中位数 + 按对数亮度加权的小双边滤波；`bake.py -- --refilter` 只重做这一步（20–45 秒）。
- 阳台夜景三个方案（`&night=`）：`n1` 程序城市、`n2` 外滩 HDRI 背景板（江景）、`n3` 两者混合。用户选 n2。
- 4096²、512 采样：光照贴图 23 分钟，扩边 3 分钟、OIDN 1.6 分钟、6 张探针 4.3 分钟，整套 32 分钟。
  像素密度（像素/米）：地板 93、墙 79、家具 112、床品 126、窗帘 158、天花板 47。人眼实时 33–42 fps（1920×1080），阳台夜景 52 fps。

### 第 5 轮：第一人称漫游（`seq=final`）

- 约 40 秒：图纸 → 搭建 → 软装成组落下 → 绕圈 + 入夜 + 下降 → 白色比例人偶走到入户门 → 镜头扎进人偶变第一人称 → 逛全屋 → 阳台推拉门滑开 → 看外滩。
- 门（`src/look/doors.jsx`）：室内门开进各自的房间、贴着墙；个别门在 `tour.js` 的 `DOOR_OVERRIDES` 里指定，不改户型数据。门开着重烘一套（`opus55-m5`，49 分钟，加了显卡温度看守：91°C 暂停、86°C 继续）。
- 房间探针在门口交叉淡化（`bake.js` 的 `pickProbe`），不再一跨门就跳。
- 用户反馈：人偶不要了；节奏太快、镜头晃，要稳、要慢；厨房、卫生间也要进去。

### 第 6 轮：去掉人偶，改成房产 VR 带看那种稳、慢

```bash
node tools/tour-path.mjs && python tools/tour-path.py           # 不开浏览器：路线画到户型上，查离墙多近、转头多快
node tools/record.mjs --smooth --q "style=e2&plan=opus55&clean&look=pro&pbr&seq=final"   # 30 帧低分辨率顺滑预览
python tools/judder.py out/floorplan-16x9-smooth.mp4 --from 14.2  # 逐帧查稳不稳
```

- 绕圈结束时相机停在入户门里面的上空，像升降臂一样直着降下来（2.8 米以下天花板才出现）。
- 镜头不再是关键帧插值，而是先算速度：沿路线每 1 厘米一个速度上限，按最大加速度正反两遍限速，积分成时间再高斯平滑；朝向按时间插值。
- 没有步伐起伏、不侧倾，俯仰基本不变（−6°）。实测：最快 0.76 米/秒，转头最快 22.5°/秒。
- 10 帧/秒的预览会把转身看成一顿一顿的，判断稳不稳要看 30 帧。
- 全片约 100 秒，超出 65–80 秒的目标。

### 第 7 轮：快一点，每个房间只扫一遍

- 落地挪到客厅中间，走两步到厨房门口，推拉门滑开。下降段按从绕圈的末速度到走路的初速度做三次 Hermite，不打钩、不急停。
- 新规划器：朝向锚点按时间插值（停留时按同一角速度匀速扫）；`sweep` 定扫的角速度；超过 YAW_CAP 35°/秒、PITCH_CAP 7°/秒的段自动放慢；横向加速度限 1.1 米/秒²；走路 ≤ 1.06 米/秒，过门 0.55。
- 每个房间：进门 → 一个方向匀速扫过看点 → 转到门口 → 走出去，不来回摇、不倒退。
- 卫生间门合页挪到西边、开 120° 收进角落；在厨房、卫生间、次卧、主卧加了几幅漫游专用的小画，扫向门口时不落在一整面白墙上（`DECOR_EXTRA`）。
- 全片 77.9 秒。

### 第 8 轮：定稿（79.9 秒）

- 卧室给的时间最多：扫得慢（约 28°/秒），床、窗边放慢多停一会儿（`linger`）；厨房、卫生间扫得紧凑（37°/秒，扫的头尾和走路叠一点：`pre` / `post`）。
- 各段：落地 2 → 到厨房门 3.2 → 厨房 7.5 → 绕餐桌 8 → 卫生间 6 → 走向次卧 5.7 → 次卧 10.4 → 走向主卧 2.7 → 主卧 11.2 → 去阳台 6.5 → 阳台 4.5（秒）。
- 正式成片 1920×1080 和 1080×1920，30 帧；1050 Ti 上 1080p 一条录约 6 分钟（2397 帧，约 150 毫秒一帧）。
- `tools/cover-stills.mjs` 取全分辨率封面静帧；README 的头图是 9.5 秒的鸟瞰机位配结尾的蓝调光照合成的，成片里没有这一帧。
