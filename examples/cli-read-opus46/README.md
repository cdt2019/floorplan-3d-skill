# Claude Code 命令行读图（Opus 4.6，默认模型，没有 skill）

2026-10-11。空文件夹里只放 `plan.png`，启动 Claude Code 2.1.87（默认模型 Opus 4.6，high effort，accept edits 模式），只说一句：
"读一下 plan.png 这张户型图：把墙、门窗、房间都读出来，尺寸以图上的标注为准，存成 plan.json"。
用时 7 分 21 秒（大部分时间在思考），输出 `plan.json`（格式是它自己定的）。

对照原始数据：
- ✅ 轴网、6 个房间的范围和面积全对，墙的位置对
- ❌ 厨房推拉门（1.5 m）读成 0.8 m 平开门
- ❌ 漏了卫生间窗
- ⚠️ 阳台推拉门宽读成 3.0 m（实为 4.2 m）；次卧窗、主卧窗位置偏 0.4–0.5 m；没读墙厚

同一张图交给 Opus 5.5 盲读（`../blind-read/`）全部读对。结论：模型版本影响很大；skill 里应该指定输出格式、提醒先用尺寸标注反算比例再量门窗。
