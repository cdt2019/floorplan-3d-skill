# 盲测：AI 只看图，能不能把户型图读对

2026-10-11。把 `plan-sheet.png`（由 `src/plan/drawPlan.js` 从示例户型数据画出来的施工图风格平面图）单独交给一个 Claude 子任务，要求它**只打开这一张图片**，不许看项目里的任何代码和数据，读出墙、门窗、房间，按 JSON 输出。读出的结果在 `result.json`。

|---|---|---|---|
| 轴网 | x：0 / 3 / 5 / 6 / 10，z：0 / 3.6 / 8.4 / 9.8 | 同左（来自图上的尺寸标注） | ✅ |

| 平开门 | 4 樘：入户 1.0、卫生间 0.8、次卧 0.8、主卧 0.9 | 4 樘，类型、中心、宽度都一致 | ✅ |

## 要说清楚的局限

这是**理想情况**：图是程序画的，线条干净，尺寸标注规范。真实场景里的户型图（楼盘宣传图、手机拍的、带水印的扫描件、手绘图）会难得多。下一步应该拿真实户型图再测一次，读错的地方如实记录。
